# Roadmap

Not built yet.

## Language and display

- Symbolic math and solve blocks
- Line breaking inside a single stage of a long equation
- Globals usable above their definition (units already are)
- Custom units that define a new base dimension or an offset scale
- Mouse selection snapped to terms (use double-click or `Alt+Up`)

## Plots

- Plots are functions of one variable only. Not built: plotting arrays or measured data
- Box zoom
- Dragging legends, notes and labels with the mouse
- An offset note (`+1e9`) for ranges far narrower than their position
- Minor grid lines
- Per-machine plot styles (colors and fonts for every sheet)
- PDF output of the picture (use SVG or PNG). A `.tex` export that includes the picture as a file instead of a pgfplots figure would need a zip
