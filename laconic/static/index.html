Welcome to LENS

LENS {{version}} · Releases · Changelog

The Laconic Engineering Notebook System: a units-aware worksheet. Type one expression per line on the left and the typeset result appears on the right as you type. Copy LaTeX line by line, or export a whole document.

Worksheets are plain-text .lens files, so they diff and merge in git. Units are marked with an apostrophe ('kN), so a bare name is always a variable.

Read the full documentation on the wiki →

Quick start Getting Started

## Simply supported beam           ## makes a heading, # a comment
L = 4.5'm
w = 12'kN / 'm
M_max = w * L^2 / 8 -> 'kN * 'm    -> converts the result to other units

One statement per line. An error on a line never stops the lines after it. Evaluation runs top to bottom, so define things before you use them.

Save (Ctrl+S) and Open (Ctrl+O) use plain-text .lens files. In Chrome or Edge, Save writes back to the file you opened; Save As (Ctrl+Shift+S) picks a new one, and renaming the sheet makes the next Save ask. Firefox and Safari download a copy each time.

Worked examples ship with the program, so they are always here. Opening one replaces the sheet in the editor:

    Worksheet syntax Worksheet Syntax

    f(x, y) = x^2 + y         your own function
T = 20'degC -> 'degF      offset units work
σ_max = 3                 Greek letters and subscripts in names
~g = 9.81'm / 's^2        ~ makes g global: !clear keeps it
v` = 2                    a mark after a name is an accent: ` dot, ! arrow, @ hat
!clear                    forget every non-global variable above
    • Operators: + - * / ^, elementwise .* ./, and -> to convert units. Only a number followed by units may skip the *: write 3*x, not 3 x.
    • Constants are pi, e and ∞ (Ctrl+G after an 8). Physical constants are units: 'R, 'k_B, 'h_P, 'N_A. Functions include sqrt abs sin cos tan exp ln log10 and heaviside.
    • Every later use of a global is written ~g; with Math keys on, the editor adds the ~ once you finish typing the name. Globals are colored and underlined in the results unless Mark globals is off.
    • A line starting with ! is a command and affects every line below it: !clear, !clearf, !noassume, !trigdeg, !short, !hide, !sigfigs n, !plot, !root, and more. Settings → Reference lists them all.
    • Units lists every unit: search by name or description, filter by a tag such as constants or thermodynamics, and click one to insert it. + tag adds a tag of your own.
    • Rename a variable, function or custom unit everywhere with Rename or F2. Comments and plot titles are left alone.

    Units Units

    • A unit starts with an apostrophe: 4.5'm, 200'GPa. Every unit in a compound gets its own: 12'kN / 'm. A bare name is always a variable, so m can be a mass while 'm is the metre.
    • Calculated results come out in the simplest SI unit (N, J, Pa, …); a line that is one typed-in quantity stays as typed. Use -> to choose another unit, or !noassume to keep the units your arithmetic produced.
    • Define your own with 'smoot = 1.7018'm. A definition applies to the whole sheet, above or below it. Units you use in every sheet go under Settings → Global units, and Save carries the definitions a sheet needs.
    • The pound is 'lbm (mass) or 'lbf (force).
    • Percent is 5'% (0.05). Currencies use ISO codes, such as 'USD, 'EUR and 'GBP, and are never converted into each other. Write an exchange rate as a variable: rate = 1.08'USD/'EUR.

    Matrices Matrices

    A = [2, -1; -1, 2]        commas across, semicolons down
F = [10; 5] * 'kN         a unit on its own is 1 of that unit
u = solve(A, F)
idx(u, 1)   elem(A, 1, 2) indexes count from 1
A * B    A .* B           matrix product, elementwise product
    S = 0
M = zeros(3, 3)
!loop i = 1 .. 3          the indented lines run for i = 1, 2, 3
  S = S + i^2             below the block, S = 14
  !loop j = 1 .. 3        a loop inside, indented under it
    elem(M, i, j) = 1/(i + j - 1)   an entry; idx(v, i) = for a vector's

    A !loop runs its lines as the sheet runs. Each line assigns a name or an entry of a matrix made above, and below the block each name holds its last value.

    There are also inv, det, transpose, eigvals, lstsq and more; the suggestion list shows them all. Every entry of a matrix shares one dimension. Paste cells from Excel or a Markdown table and they become a matrix (Ctrl+Shift+V pastes plain text).

    Material properties Material Properties

    rho  = props("D", "T", 20'degC, "P", 1'atm, "Water")
Tsat = props("T", "P", 5'bar, "Q", 0, "Water") -> 'degC
Tc   = props("Tcrit", "Water")       fixed properties need no state
w    = haprops("W", "T", 25'degC, "P", 1'atm, "R", 0.5)   humid air

    props looks up about 130 fluids, mixtures and brines from CoolProp, the way CoolProp's PropsSI does: the output key, up to two state inputs, then the fluid. Inputs take any compatible unit; the result is in SI, so convert it with ->. Type " inside props( for the keys and fluids. haprops gives humid air the way HAPropsSI does: the output key and three state inputs, one of them the pressure (R relative humidity, W humidity ratio, B wet bulb, D dew point).

    Plots Plots

    !plot M(x), V(x), x = 0'm .. L
  title: Bending moment
  ylabel: M (kN·m)
  color 2: red
  points: D               measured points over the curves: an x row and a y row, or x, y

!plot t, s                points alone: two vectors, or a matrix D

    Indented key: value lines set the details; !plotspec key: value sets a default for every plot below it. Drag the plot to pan, Ctrl + wheel to zoom, double-click to reset. The new view is written back into the sheet as xview: and yview: lines, so Ctrl+Z undoes it. Each plot saves as SVG or PNG, and the LaTeX export draws it with pgfplots.

    Solving and optimizing Solving and Optimizing

    x = 1'm                   starting values come from ordinary variables
y = 1'm
!root x, y
  equation: x^2 + y^2 = 4'm^2
  equation: x = y
z = x * 2                 below the block, x and y hold the solution

!minimize d                or !maximize
  objective: cost(d)
  constraint: d >= 0.5'm
  bounds d: 0'm .. 3'm

    Solvers can be slow, so they never run while you type. Under the block, Run solves it, Interrupt stops a stuck one, Auto re-solves a moment after its inputs change, Verify solves again and compares, and Log shows what happened. The answer is stored in the block as a #@ result line, so a saved sheet opens with its answers.

    The status under the block is ✓ up to date, ⚠ out of date, ○ not run yet, ⟳ running, or ✕ failed. Every line computed from an out-of-date block gets a ⚠ too.

    D = [0, 1, 2, 3; 1.1, 2.9, 5.2, 7.1] * 'm   one column per point: x row, then y row
!regression a, b, c       y = a + b x + c x², lowest power first
  data: D                 or two vectors: data: t, s
  model: y(x) = a + b*exp(c*x)  optional: any function instead; y(x, z) takes data: x, z, y
  r2: R2                  optional: a name for R²

    !regression fits a polynomial by least squares as the sheet runs, with no Run button. Each coefficient gets the units of y / xk, and the names it defines hold the fit below the block.

    Symbolic math Symbolic Math

    $m, $a, $F                $ declares symbols; ~$g a global one
p = m*a                   a symbolic result, shown as math
!symsolve a               solve for symbols with sympy, as you type
  equation: F = m*a       below the block, a = F/m
m = 2'kg
F = 10'N
acc = a                   every symbol has a value now: 5 m/s²

    A symbolic result has no units: numbers without units go into it, and a number with units is an error until every symbol in the expression has a value, when it is worked out with units as usual. With several solutions, pick: 2 chooses the one the unknowns hold below the block.

    Symbols are shown in the theme's Symbols color; only globals are underlined, so a global symbol is in the symbol color and underlined. Hover one to see where it was declared. !clearsym removes the non-global symbols and keeps every other variable.

    Output and export Output and Export

    • Typeset / LaTeX switches the right-hand side between rendered math and LaTeX source, with a Copy button per line. The menu beside it chooses how each snippet is wrapped: inline, \[ \] or align*.
    • Export → LaTeX document writes a complete .tex document (siunitx v3 or newer; pgfplots when a sheet has plots).
    • Export → PDF opens the print dialog on a plain copy of the results, broken into pages so no calculation is split; choose Save as PDF there. lens sheet.lens --pdf out.pdf writes the same PDF from the command line (it needs Chrome, Chromium or Edge).
    • Export → Markdown note writes a .md note for Obsidian: headings, comments as text, each calculation as a $$ block and plots as images. Commands such as !clear are left out.
    • !sigfigs n, !sigfigsbig n, !decplace n and !short change how results are printed, never their values.
    • From the command line, lens sheet.lens --tex out.tex and --md out.md write the same files, and --plots DIR writes each plot as SVG.

    Editor shortcuts Editor Shortcuts

    With Math keys on, the editor shapes the text as you type. They are off on comment lines and on the text under a plot or solver: titles, labels, a note's text, the method.

    • / makes a fraction from the term on its left, ^ opens an exponent, \ a square root. → or ) steps out of the slot. With text highlighted, they apply to the whole terms it touches.
    • . after a name makes a subscript: M.max becomes M_max.
    • Ctrl+G turns the character before the caret into an extended character: a Greek letter (s to σ), 8 to ∞ or V to ∀. Press it again to undo. Ctrl+M makes an array and Alt+T transposes.
    • Double-click selects a whole term, and Alt+↑ widens the selection step by step.
    • Suggestions pop up after ' (units), ! (commands) and two letters of a name, or by hand with Ctrl+Space. Tab accepts.

    Settings Settings

    Settings has six parts: Reference (every key and command), Layout (side by side or stacked; Alt+L switches), Updates (whether LENS checks for a new release), Extended characters (the table behind Ctrl+G), Global units and Theme (colors, fonts, text size and paper style). Settings are stored on this machine, so every browser shows the same ones, and the command line uses the same global units. Press F1 any time to bring this window back.
