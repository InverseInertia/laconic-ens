Math keys

These keys edit the source text. The result column shows the typeset math. They are inactive on comment lines (starting with #) and can be switched off with the Math keys box.

/Fraction. Takes the term on the left as numerator and the term on the right, if any, as denominator. a/ gives a/( ). After A. it gives A./
\Radical. sqrt( ), or wraps the selection
.Subscript after a name. M.max gives M_max. After a number it stays a decimal point
^Exponent slot. x^( )
→ or )Leave a slot. If it holds one simple term the parentheses go away: x^(2) becomes x^2
EnterWith only closing brackets left on the line, finishes the line instead of splitting it
BackspaceIn an empty slot, removes the slot and its ^, / or sqrt. After , or ; , removes the separator and its space together
Ctrl+MArray. [ ], or wraps the selection
, ;A space is added after them automatically. In an array, , separates columns and ; separates rows
Ctrl+T
Alt+T		Transpose the term on the left or the selection. Press again to undo. Browsers reserve Ctrl+T for a new tab, so use Alt+T in a normal tab
Ctrl+[
Ctrl+Shift+[		Index the term on the left or the selection. Ctrl+[ gives idx(A, i), typeset Ai: one element of a vector, or one row of a matrix. Ctrl+Shift+[ gives elem(A, i, j), typeset Ai,j: row and column. The caret lands in the index slot. Counting starts at 1. Indexes can be indexed too: idx(elem(A, 1, 2), 3)
Ctrl+GGreek letter for the character before the caret. Press again to go back. Edit the mapping under Greek
Ctrl+/
Ctrl+\		Type a literal / or \ with no fraction or radical slot
= + - *Spaces are added around them (and around ->, .*, ./ and fractions), and a second space is ignored. A sign (-3, x^-1) and 1e-3 stay tight. Backspace removes a spaced operator in one press
` ! @After a variable name: x` puts a dot over it (x`` two dots), F! an arrow, a@ a hat. F_x! marks the F and keeps the subscript. Each marked name is a separate variable
~A variable or function name that starts with ~ is global and survives !clear / !clearf
!clearfOn its own line, removes every non-global function above it
!clearOn its own line, removes every non-global variable above it
!noassume !assumeBelow !noassume, results keep the units that come out of the arithmetic (kN*m, not J) unless you convert with ->. !assume returns to SI
!short !longBelow !short, each line shows only its final result, with its unit but no intermediate steps. !long restores the full display
!trigdeg !trigradSet the angle unit for sin, cos, tan on bare numbers, and for asin, acos, atan results. Radians by default; explicit units such as 30'deg always work

Welcome to LENS

What it is

LENS is a worksheet for engineering calculations. You write one expression per line on the left, and the typeset result appears on the right as you type. Every number can carry a unit, and the units are checked for you, so kN and mm mix correctly and a mismatch shows up as an error on that line.

## Simply supported beam           ## makes a heading, # a comment
L = 4.5'm
w = 12'kN / 'm
M_max = w * L^2 / 8 -> 'kN * 'm    -> converts the result to other units

Units

  • A unit starts with an apostrophe: 4.5'm, 200'GPa. Every unit in a compound gets its own: 12'kN / 'm.
  • A bare name is always a variable, so m can be a mass while 'm is the metre.
  • Results come out in plain SI (N, J, Pa, …). Use -> to choose another unit, or !noassume to keep the units your arithmetic produced.
  • Define your own with 'smoot = 1.7018'm. Units you use in every sheet can be stored under Settings.

Typing math

With Math keys on, the editor shapes the text as you type. They are off on comment lines.

  • / makes a fraction from the term on its left, ^ opens an exponent, \ a square root. → or ) steps out of the slot.
  • . after a name makes a subscript: M.max becomes M_max.
  • Ctrl+G turns the letter before the caret into Greek (s to σ). Press it again to undo.
  • Double-click selects a whole term, and Alt+↑ widens the selection step by step.
  • Suggestions pop up after ' (units), ! (commands) and two letters of a name. Tab accepts.

Variables and functions

f(x, y) = x^2 + y         your own function
~g = 9.81'm / 's^2        ~ makes a variable global, so !clear keeps it
T = 20'degC -> 'degF
F` = 2   v! = 5   a@ = 1  dot, arrow and hat accents
!clear                    forget every non-global variable above

Rename a variable, function or custom unit everywhere with Rename or F2. Evaluation runs top to bottom, so define things before you use them.

Matrices

A = [2, -1; -1, 2]        commas across, semicolons down
F = [10; 5] * 'kN
u = solve(A, F)
A * B    A .* B           matrix product, elementwise product

There are also inv, det, transpose, eigvals and more; the suggestion list shows them all. Paste cells from Excel or a Markdown table and they become a matrix.

Plots

!plot M(x), x = 0'm .. L
  title: Bending moment
  ylabel: M (kN·m)

Indented key: value lines set the details. Drag the plot to pan, Ctrl + wheel to zoom, double-click to reset. The new view is written back into the sheet as text, so Ctrl+Z undoes it. Each plot can be saved as SVG or PNG.

Material properties

rho = props("D", "T", 20'degC, "P", 1'atm, "Water")

props looks up fluids and materials (density, viscosity, enthalpy, saturation temperatures, …) from CoolProp.

Getting results out

  • Typeset / LaTeX switches the right-hand side between rendered math and LaTeX source, with a Copy button per line. The menu beside it chooses how each snippet is wrapped.
  • Export LaTeX writes a complete .tex document. Save and Open use plain-text .lens files, which carry the custom units they depend on.
  • !short hides the working and shows only each final result. !long brings it back.

Settings

Settings holds the colors, fonts and paper style, the Greek letter table behind Ctrl+G, and your global units.

Rename symbol

Changes every use of a variable or function in the sheet. Units, comments and commands are left alone. With the caret on a name, F2 fills in the old name.

Global units

Units defined here exist in every sheet on this instance and are stored with your settings on this machine. A saved .lens file or exported .tex that uses one carries its definition, so it opens correctly elsewhere. A definition can use numbers and earlier units. For a unit that only one sheet needs, write 'smoot = 1.7018'm in the sheet instead.
