Math keys

These keys edit the source text. The result column shows the typeset math. They are inactive on comment lines (starting with #) and can be switched off with the Math keys box.

Welcome to LENS

The Laconic Engineering Notebook System: a units-aware worksheet. Type one expression per line on the left and the typeset result appears on the right as you type.

Read the full documentation on the wiki →

Quick start Getting Started

## Simply supported beam           ## makes a heading, # a comment
L = 4.5'm
w = 12'kN / 'm
M_max = w * L^2 / 8 -> 'kN * 'm    -> converts the result to other units

One statement per line. An error on a line never stops the lines after it. Evaluation runs top to bottom, so define things before you use them. Save (Ctrl+S) and Open (Ctrl+O) use plain-text .lens files. In Chrome or Edge, Save writes back to the file you opened; Save As (Ctrl+Shift+S) picks a new one. Other browsers download a copy each time.

Worked examples ship with the program, so they are always here. Opening one replaces the sheet in the editor:

    Worksheet syntax Worksheet Syntax

    f(x, y) = x^2 + y         your own function
~g = 9.81'm / 's^2        ~ makes g global, so !clear keeps it; use plain g after
T = 20'degC -> 'degF
F` = 2   v! = 5   a@ = 1  dot, arrow and hat accents
!clear                    forget every non-global variable above
    • Operators: + - * / ^, elementwise .* ./, and -> to convert units. Only a number followed by units may skip the *.
    • Names may use Greek letters and subscripts (σ_max). Constants are pi, e and ∞ (Ctrl+G after an 8).
    • A line starting with ! is a command and affects every line below it: !clear, !noassume, !trigdeg, !short, !sigfigs n, !plot, !root, and more.
    • Rename a variable, function or custom unit everywhere with Rename or F2.

    Units Units

    • A unit starts with an apostrophe: 4.5'm, 200'GPa. Every unit in a compound gets its own: 12'kN / 'm. A bare name is always a variable.
    • Results come out in the simplest SI unit (N, J, Pa, …). Use -> to choose another, or !noassume to keep the units your arithmetic produced.
    • Define your own with 'smoot = 1.7018'm. Units you use in every sheet can be stored under Settings. Saving a sheet carries the definitions it needs.
    • The pound is 'lbm (mass) or 'lbf (force).
    • Percent is 5'% (0.05). Currencies use ISO codes, such as 'USD, 'EUR and 'GBP, and are never converted into each other. Write an exchange rate as a variable: rate = 1.08'USD/'EUR.

    Matrices Matrices

    A = [2, -1; -1, 2]        commas across, semicolons down
F = [10; 5] * 'kN
u = solve(A, F)
A * B    A .* B           matrix product, elementwise product

    There are also inv, det, transpose, eigvals and more; the suggestion list shows them all. Paste cells from Excel or a Markdown table and they become a matrix.

    Material properties Material Properties

    rho = props("D", "T", 20'degC, "P", 1'atm, "Water")

    props looks up fluids and materials (density, viscosity, enthalpy, saturation temperatures, …) from CoolProp.

    Plots Plots

    !plot M(x), x = 0'm .. L
  title: Bending moment
  ylabel: M (kN·m)

    Indented key: value lines set the details. Drag the plot to pan, Ctrl + wheel to zoom, double-click to reset. The new view is written back into the sheet as text, so Ctrl+Z undoes it. Each plot can be saved as SVG or PNG.

    Solving and optimizing Solving and Optimizing

    x = 1'm   y = 1'm         starting values come from ordinary variables
!root x, y
  equation: x^2 + y^2 = 4'm^2
  equation: x = y

!minimize d                or !maximize
  objective: cost(d)
  constraint: d >= 0.5'm
  bounds d: 0'm .. 3'm

    Solvers can be slow, so they never run while you type. Under the block, Run solves it, Interrupt stops a stuck one, Auto re-solves a moment after its inputs change, Verify solves again and compares, and Log shows what happened. The answer is stored in the block as a #@ result line. If an input changes, the block and every line computed from it show ⚠ out of date.

    Output and export Output and Export

    • Typeset / LaTeX switches the right-hand side between rendered math and LaTeX source, with a Copy button per line. The menu beside it chooses how each snippet is wrapped.
    • Export LaTeX writes a complete .tex document (siunitx v3 or newer; pgfplots when a sheet has plots).
    • !sigfigs n, !decplace n and !short change how results are printed, not their values.

    Editor shortcuts Editor Shortcuts

    With Math keys on, the editor shapes the text as you type. They are off on comment lines.

    • / makes a fraction from the term on its left, ^ opens an exponent, \ a square root. → or ) steps out of the slot.
    • . after a name makes a subscript: M.max becomes M_max.
    • Ctrl+G turns the letter before the caret into Greek (s to σ). Press it again to undo.
    • Double-click selects a whole term, and Alt+↑ widens the selection step by step.
    • Suggestions pop up after ' (units), ! (commands) and two letters of a name. Tab accepts.

    Settings Settings

    Settings holds the colors, fonts and paper style, the Greek letter table behind Ctrl+G, and your global units. Press F1 any time to bring this window back.

    Rename symbol

    Changes every use of a variable, function or custom unit in the sheet. Replacing a standard unit asks you to confirm and swaps it for another unit, or a new one that gets a definition. Comments and commands are left alone. With the caret on a name, F2 fills in the old name.
